What this is not. PNG, PDF and EPS come out of the same geometry on the server, but only SVG can be drawn here, so the preview is the SVG one. The logo you pick is read in your browser and inlined; the package would run it through its twelve checks first and refuse a remote URL, a stream wrapper, a MIME mismatch or a decompression bomb. Everything else — the matrix, the shapes, the colours, the report — is the package's own code, ported and checked against it.
